Tentang AI ChatBot 122

Arsitektur Sistem

Aplikasi ini terhubung langsung ke backend server lokal melalui endpoint /api/chat dan memanfaatkan streaming real-time (Server-Sent Events) untuk menampilkan respon secara langsung.

Pintasan Tombol (Shortcuts)

  • Enter : Mengirim pesan
  • Shift + Enter : Menambahkan baris baru
  • Ctrl + K : Membuka percakapan baru
  • Esc : Menutup jendela dialog / modal

Fitur Interaktif Unggulan

Real-time SSE Streaming Voice Input (Speech to Text) Text to Speech (Dengar Respon) Syntax Highlighting & Salin Kode Ekspor ke Markdown (.md) Riwayat Lokal (Auto-Save) Tema Gelap & Terang Sound Feedback Sintesis
